# Ajisai v2.0.0 release target

Ajisai v2.0.0 is the target stable release for the rebuilt product. The
workspace remains at `0.1.0` until every release gate has evidence; setting the
target does not imply that publication is complete.

## Required gates

- Native Pipeline/Workflow format and Hop migration behavior are versioned,
  validated, and covered by immutable fixtures.
- CLI, engine, and persisted records have stable contracts, bounded resource
  behavior, and explicit failure/cancellation states.
- Hop 2.19.0 differential results are measured on pinned hardware with matching
  semantics, and unsupported differences are published.
- Security review, dependency/license policy, SBOM, secret scan, artifact
  checksums, and independent verification are complete.
- Supported OS packages, install/upgrade/rollback paths, and limitations are
  tested on clean machines.

## Version transition

The first publishable tag is `v2.0.0`. Until the gates above pass, release
artifacts must identify themselves as a pre-release candidate and must not claim
Hop parity or production readiness.
